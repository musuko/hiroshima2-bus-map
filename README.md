# hiroshima2-bus-map
## 本日の広島県のバス時刻表を調べることができます。
### 使い方
- https://musuko.github.io/hiroshima2-bus-map/
- バス事業者を選択
- 使いたいバス停を地図で選択すると、そのバス停の時刻表が開く
- その時刻表の時刻部分をクリックすると、そのバスの始点から終点までのルートと時刻表が表示される。
### バス会社
- 広島電鉄
- 広島バス
- 広島交通
- 芸陽バス
- 備北バス
- HD西広島
- フォーブル
- JRバス中国
- 佐々木観光(ハートバス)
- 呉市生活バス
- 廿日市自主運行バス
- おのみちバス
- 朝日交通(阿戸線)
- 中国バス
- 鞆鉄道
- 衣笠バスカンパニー
- 江田島バス
### 他機能
- 表示されたバスを選択すると、そのバスの目的地や時刻表が表示される。
### 課題
- 地図にバスの現在地を有効に表示できない。2時間くらい遅れることもあり、実用的でない。
- 元データが更新されたとき、自動で時刻表に反映させる
- 他の日付の時刻表を表示する
